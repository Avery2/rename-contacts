# Eggify Contacts

The script gives the 🥚 nickname to contacts whose nickname is empty. When one
of those contacts also has no photo, it adds the egg image.

Existing nicknames, photos, and contact notes are left untouched. Before making
changes, the script shows exactly how many nicknames and photos it will add.

## Run it

1. In Contacts, make a backup with **File → Export → Contacts Archive**.
2. Open `rename_contacts.applescript` in Script Editor and click **Run**.
3. Select `egg.png` when prompted and allow access to Contacts if macOS asks.
4. Review the counts in the confirmation dialog, then click **Continue**.

The script and image are both stored at the repository root.
